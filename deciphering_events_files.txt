Interpreting Gacha Data
Each line in the Gacha data file is split into the header and the gachas.

Some values I've just written 0. That just means I don't know what the number is supposed to be (so you can probably ignore it).

The Header
The header consists of the first nine values. These are, in order:

The start date
The start time
The end date
The end time
The minimum version number
The maximum version number
0
0
The gacha type
For the gacha type, 0 means Normal Capsules, 1 means Rare Capsules, 4 means Event Capsules

The Gachas
The first value is a number X denoting the number of gachas. Each gacha consists of 15 values:

The Gacha ID. Visit

https://ponos.s3.dualstack.ap-northeast-1.amazonaws.com/information/appli/battlecats/gacha/rare/en/R{XXX}.html

replacing {XXX} with the id. For Normal capsules, replace rare with normal and RXXX with NXXX. For event capsules, replace rare with event and RXXX with EXXX.

The price per roll, in catfood. (Only relevant for rare capsules.)
0
Usually 0, but 4 means "increasing capsules" is available, 3448 means lucky tickets will be obtained for every draw, and 3452 means both.
Chance for a normal reward (out of 10000).
0
Chance for a rare reward.
0
Chance for a super rare reward.
0
Chance for an uber super rare reward.
Usually 0, but if this number is 1 then that means a "guaranteed" draw is available.
Chance for a legendary uber super rare reward.
0
A message (which usually gives the name of the event).
